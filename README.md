# 장르별 영화추천 서비스

## **Project Summary**

### **프로젝트 개요**

**주제:** 파이썬 기반 장르별 랜덤 영화 추천 GUI 프로그램 개발

**기획 배경:** OTT 및 미디어 콘텐츠의 홍수 속에서 어떤 영화를 볼지 고민하는 사용자들의 '선택 장애'를 해결하기 위해, 장르만 입력하면 무작위로 영화를 추천해 주는 간편한 프로그램을 기획하였다.

**사용 데이터:** 네이버 시리즈온(Naver Series On) 영화 랭킹 및 상세 정보 (제목, 장르, 평점, 줄거리, 포스터 이미지).

---

### **주요 기술**

**데이터 수집:** BeautifulSoup, requests를 활용한 정적 웹 크롤링.

**데이터 처리:** Pandas를 사용하여 수집된 데이터를 DataFrame으로 변환 및 CSV 파일로 저장/관리.

**GUI 개발:** tkinter를 활용하여 메인 윈도우, 입력창, 버튼, 팝업창 구현.

**이미지 처리:** PIL, io.BytesIO를 사용하여 웹 URL 상의 포스터 이미지를 GUI 내에 출력.

---

### **구현 기능 및 개선점**

**기능 로직**

- 사용자가 GUI 입력창에 원하는 '장르' 입력 (예: 액션, 드라마).
- Pandas가 CSV 파일에서 해당 장르의 영화 데이터를 필터링.
- random.sample 모듈을 이용해 필터링 된 목록 중 3개의 영화를 무작위로 선정.
- 새로운 팝업창에 선정된 3개 영화의 포스터와 상세 정보를 시각적으로 출력.

**향후 개선점**

현재 CSV 기반의 파일 시스템을 Oracle, MySQL 등 **RDBMS**로 고도화하여 대용량 데이터 처리 성능을 확보하고, 텍스트 위주의 UI를 더욱 직관적인 이미지 중심 UI로 개선할 계획이다.
